## 1. 비주얼 방향 — **시스템 네이티브 미니멀** (확정)

iOS 26 기본 룩 + Liquid Glass를 그대로 쓴다. 콘텐츠(썸네일·제목)가 주인공이고
앱의 크롬(chrome)은 최대한 시스템에 맡긴다. Apple 기본 앱(메모·미리알림)처럼
익숙하게 느껴지는 것이 목표 — 링크 "소비"가 목적인 유틸리티이기 때문.

**원칙 3가지**
1. 시스템 컴포넌트 우선 — 커스텀은 시스템에 없는 것(저장 카드·필터 칩·출처 배지)만.
2. 색은 아껴 쓴다 — 화면의 색은 콘텐츠 썸네일과 카테고리 색에서만 나온다.
3. 텍스트 계층은 Dynamic Type으로만 — 커스텀 폰트 크기 없음.

## 2. 컬러

| 토큰 | 값 | 용도 |
|---|---|---|
| 배경 | 홈(plain 리스트) `systemBackground` · 설정/시트 `systemGroupedBackground` | 화면 배경 |
| 텍스트 | `label` / `secondaryLabel` / `tertiaryLabel` | 제목 / 메타 / 플레이스홀더 |
| **틴트(브랜드)** | **인디고 계열 1색** (`#5B5BD6` 근방, 다크 `#7B7BE8`) | 미열람 점 · 선택 칩 · Primary 버튼 · 앱 아이콘 리본 |
| 카테고리 팔레트 | 시스템 12색 (red·orange·yellow·green·mint·teal·cyan·blue·indigo·purple·pink·brown) | 카테고리 색 선택지 — 커스텀 색 없음 |

- 브랜드 색은 **하나**다. 성공/경고 등 상태색은 시스템 시맨틱(`systemGreen`/`systemRed`) 그대로.
- 다크 모드는 시맨틱 컬러가 자동 처리 — 커스텀 다크 팔레트 없음.

## 3. 타이포그래피

**시스템 폰트(SF Pro) + Dynamic Type 텍스트 스타일만 사용.**
템플릿의 Pretendard `AppFont`는 쓰지 않는다(템플릿 다이어트의 일부) —
시스템 네이티브 방향에서는 시스템 폰트가 곧 브랜드다.

| 용도 | 스타일 |
|---|---|
| 홈 타이틀 "갈피" | `.largeTitle` (네비바 large title) |
| 링크 셀 제목 | `.body` 2줄 제한 |
| 셀 메타 라인 (출처 · 3회 · 2일 전) | `.footnote` + `secondaryLabel` |
| 필터 칩 | `.subheadline` |
| 저장 카드 제목 | `.headline` |
| 섹션 헤더·버튼 | 시스템 기본 |

## 4. Shape & Liquid Glass

- 모서리: 셀·썸네일 컨테이너는 `ConcentricRectangle` 패턴(템플릿 규약 유지).
  썸네일 단독은 `RoundedRectangle(cornerRadius: 12)`.
- Glass 사용 지점 (그 외 커스텀 글래스 금지):

| 위치 | Variant |
|---|---|
| 네비바·툴바·시트 | 시스템 기본 (자동 Glass) |
| 필터 칩 바 (스크롤 시 콘텐츠 위에 뜸) | `.regular.interactive()` |
| 저장 카드 [저장] 버튼 | `.glassProminent` |
| 보조 버튼 | `.glass` |

## 5. 핵심 컴포넌트 명세

### 링크 셀 (홈 리스트)
```
[썸네일 56×56, 라운드 12]  제목 (.body, 2줄)
  └ 없으면 출처 아이콘      메타: {출처배지} · 3회 · 2일 전 (.footnote)
파란 점(틴트 8pt) = 미열람, 제목 좌측    ★ = 즐겨찾기, 우측
스와이프: (좌→우) 읽음 토글 / (우→좌) 카테고리 이동 · 아카이브 · 삭제
```

### 필터 칩 바 (홈 상단, 가로 스크롤)
`전체 · 미열람 N · 즐겨찾기 · 받은함 · {카테고리들}` — 선택 = 틴트 채움 캡슐,
비선택 = Glass 캡슐. 카테고리 칩은 앞에 색 점.

### 출처 배지
SF Symbol + 텍스트 없는 미니 배지(높이 16pt) — `youtube`(play.rectangle) ·
`instagram`(camera) · `kakao`(message) · `web`(globe). 색은 `secondaryLabel` 단색.

### 저장 카드 (Share Extension 시트, medium detent)
```
[썸네일·제목 로딩 영역 (스켈레톤 → 결과)]   [출처 배지]
[카테고리 칩 가로 스크롤 — 마지막 사용 자동 선택]
[메모 입력 (선택, 1줄 → 확장)]
[저장 — .glassProminent 풀폭]
```

### 빈 상태 (홈·필터 결과 없음)
`ContentUnavailableView` 시스템 컴포넌트. 홈 최초 빈 상태만 커스텀:
책갈피 일러스트 + "공유 시트에서 갈피를 눌러 첫 링크를 꽂아보세요" + 온보딩 재진입 버튼.

## 6. 화면별 비주얼 요점

| 화면 | 요점 |
|---|---|
| ① 보관함 홈 | Large title, 필터 칩 바, plain 리스트(그룹 카드 아님 — 밀도 우선), `.searchable` |
| ② 저장 카드 | 위 명세. 3초 안에 끝나는 밀도 — 스크롤 없이 한 화면 |
| ③ 링크 편집 시트 | medium detent. 상단 썸네일+제목 헤더, 메모 필드, 카테고리 선택 행, 정보 그리드(조회·최근 열람·저장일·출처) |
| ④ 카테고리 관리 | 시스템 리스트 + EditMode(순서·삭제). 색 12개·아이콘 SF Symbol 그리드 피커 |
| ⑤ 설정 | 순수 시스템 grouped 리스트. 커스텀 요소 없음. iCloud 상태 행(체크/주의 아이콘) |
| ⑧ 온보딩 | 풀스크린 1~2장: 공유 시트에서 갈피 켜는 법 스크린샷 중심 + 활성화 버튼 |

## 7. 위젯

- 스몰: 미열람 숫자 대형(`.largeTitle` rounded) + "안 읽은 갈피" + 리본 심볼. 배경 시스템.
- 미디엄: 좌측 미열람 숫자 블록 + 우측 최근 저장 2개(미니 셀). 딥링크는 설계 문서 §7-④.

## 8. 앱 아이콘

책갈피 리본 심볼 단독 + 단색 배경(브랜드 인디고). 텍스트 없음.
iOS 26 아이콘 규격(라이트/다크/틴티드 3종).

## 9. 접근성

- Dynamic Type 전 단계 대응 (셀 레이아웃은 `ViewThatFits` 없이 자연 확장 허용)
- 터치 타겟 최소 44pt (필터 칩 포함)
- VoiceOver: 셀 = "제목, 출처, 미열람 여부, 조회 정보" 결합 레이블. 파란 점은 색만으로 전달 금지 — 레이블에 "안 읽음" 포함
- 위젯·배지 숫자에 `accessibilityLabel`

## 10. `/design` 캔버스 시안 지침

방향은 확정(시스템 네이티브 미니멀)이므로, 시안 2~3개는 **홈 리스트 밀도·셀 형태 변주**로 뽑는다:

1. **컴팩트 리스트** — 썸네일 56pt, 밀도 최우선 (위 명세 기본값)
2. **레귤러 리스트** — 썸네일 72pt + 여백 넉넉, 즐겨찾기·미열람 강조 큼
3. (선택) **하이브리드** — 미열람 상단 가로 카드 캐러셀 + 아래 컴팩트 리스트

시안 화면: 보관함 홈 + 저장 카드 2개 화면을 방향별로. 선택 후 본 시안에서 ③~⑧ 전개.
